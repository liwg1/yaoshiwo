## 一句话

SafeVault 正式更名为 **钥匙窝 YaoShiWo**：换了个百度上独一无二的名字，外加 4 处让日常使用更顺手的改动。

## 更名说明

叫 SafeVault 的软件与项目太多，用户在搜索引擎里翻几页都找不到官网。新名字「钥匙窝」取自「密码是钥匙，钥匙该待在自己家里」，在搜索引擎上零竞争。

**改名只改外壳**：数据库文件、设置、浏览器扩展配对全部不变，用户无需迁移任何数据。
内部标识（localStorage 键、扩展令牌请求头、`appId`、配置目录 `%APPDATA%\safevault`）刻意保持不变，以保证升级时设置与扩展配对不丢失。

## 本版改动

| # | 改动 | 说明 |
| --- | --- | --- |
| 00 | 更名为「钥匙窝 YaoShiWo」 | 程序名、安装包名、托盘、解锁页、官网、扩展、封面全部换新 |
| 01 | 关闭窗口 ≠ 退出程序 | 关闭默认收进系统托盘，后台继续待命，浏览器扩展照常自动填充与保存；首次关闭会询问，并可在「设置 → 点击关闭按钮时」固定为 每次询问 / 放到状态栏 / 永久关闭 |
| 02 | 默认不再自动锁定 | 只有主动点「锁定」或按 `Ctrl+L` 才锁定，避免闲置锁定导致扩展失效 |
| 03 | 「最近使用」支持逐条删除 | 首页最近打开列表每项右侧有删除按钮，仅从列表移除，不动数据库文件 |
| 04 | 重复的密码历史可一键清理 | 只有密码真正变化才写历史快照；历史里的重复记录可在条目详情或「设置 → 数据库维护」清理，**清理前自动备份数据库** |

此外还修正了：退出时先落盘再退出（托盘「退出钥匙窝」不再丢未保存改动）、升级装新版时对「程序正在运行」的提示更明确。

## 升级须知

1. **先彻底退出旧版**：托盘图标右键 → 退出。直接点窗口关闭按钮只是收进托盘，程序仍在运行，会导致安装时文件被占用。
2. 安装新版。`appId` 未变，安装包会就地覆盖旧版；但**桌面上旧的 SafeVault 快捷方式仍指向旧程序**，建议先卸载旧版（设置 → 应用）或至少删掉旧快捷方式。
3. 数据无需迁移：密码库仍是原来的 `.kdbx` 文件。**升级前建议先复制一份备份**——主密码丢失无法找回。

## 兼容性

- 数据库格式：KDBX 3.1 / 4.0 / 4.1（Argon2 与 AES-KDF 均支持）。
- 与 KeePass 2.x **双向兼容**：KeePass 打开本软件保存的文件、本软件打开 KeePass 保存的文件均正常。
- 本版修正了 KDBX 4.x 时间字段的序列化格式（必须为 8 字节小端秒数 + Base64，早前版本写成 ISO 文本会导致 KeePass 报「输入的不是有效的 Base-64 字符串」）。相关说明见 `CHANGELOG.md` 与 `README.md`。
