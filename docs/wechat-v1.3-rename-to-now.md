**摘要**：改名只是开始。这几天我们把官网域名理顺、证书装好、备案落实、源码开源，也把「浏览器扩展怎么装」这件事彻底讲明白了。这篇把 v1.2.0 以来所有改动一次说清。

## 一、先说结论

10 月 14 日，SafeVault 正式改名 **钥匙窝 YaoShiWo**。

改名之后我们没有停下来。到今天，下面这些事都已经落地：

- 官网有了正式域名 <https://www.yaoshiwo.cn>，HTTP 自动跳 HTTPS
- 证书覆盖 `yaoshiwo.cn` 与 `www.yaoshiwo.cn`，到期自动续
- 首页底部完成 ICP 备案公示：**陕ICP备2026029660号**
- 源码在 GitHub 公开（MIT）：<https://github.com/liwg1/yaoshiwo>
- 官网的下载包、GitHub Releases、SHA256 校验值三处一致
- 最新版 **v1.3.0**：把浏览器扩展的安装步骤从头到尾写清楚

下面按版本和时间线，把每一项改动说细一点。

## 二、v1.2.0（10 月 14 日）：改名这一版

主线只有一件事：**软件有了自己的名字**。密码是钥匙，钥匙该待在自己家里。

名字换了，内核没换：依旧是本地加密、不上传云端、兼容 KeePass 的 `.kdbx`。你的数据库文件、设置、浏览器扩展配对全部照旧。

同一版里还顺手修了四处「用得别扭」的地方：

1. **关掉窗口 ≠ 退出程序。** 点关闭默认收进状态栏，后台继续待命，浏览器扩展照样能填充和保存。首次关闭会问一次，之后可以在「设置 → 点击关闭按钮时」固定成：每次询问 / 放到状态栏 / 永久关闭。
2. **不再自动锁定。** 以前到点自动锁，人还在电脑前，浏览器扩展却悄悄失效了 —— 这类「静默失败」比不锁更难受。现在只有你主动点「锁定」或按 `Ctrl`+`L` 才锁。
3. **「最近使用」可以删了。** 首页最近打开列表每项右侧有删除按钮，只从列表移除，不动数据库文件。
4. **重复的密码历史一键清理。** 现在只有密码真正变化才留快照，历史里的重复记录能在条目详情或「设置 → 数据库维护」里清掉，清理前自动备份。

> 一个容易被忽略的细节：产品改名了，但**内部标识刻意保持不变**（`appId`、用户配置目录 `%APPDATA%\safevault`、扩展请求头 `x-safevault-token`）。所以旧版可以直接被新版覆盖安装，你的设置和扩展令牌不会丢。

## 三、浏览器扩展 v1.2.1（10 月 16 日）：只动扩展，不用重装软件

这版主程序没变，只更新了扩展，重新加载一下扩展包就行。两处改动都来自真实吐槽：

1. **下拉列表改成按账号选。** 以前主行加粗显示的是网站地址 —— 同一个网站每行都一样，等于废话；用户名反倒缩在灰色小字里。现在主行是**加粗的用户名**，标题相同的条目不再重复地址；只有你给条目起的标题各不相同时，才在下面补一行小字，方便区分多个账号。
2. **修复两个钥匙图标不对齐。** 同一个登录框里用户名框和密码框宽高经常不一样，图标各自贴自己的右边缘，看起来就是错开的。现在同一个登录框内的输入框共用一列图标，对齐到最宽那个框的右边缘，并且各自垂直居中。

顺带把扩展包改成脚本打包：PowerShell 的 `Compress-Archive` 生成的 zip 条目名带反斜杠，Chrome 解压后根本加载不了 —— 这个坑踩一次就够了。

## 四、v1.3.0（10 月 20 日）：把「扩展怎么装」讲到不用再问

改完之后后台最多的提问是：**浏览器扩展到底怎么装？** 所以这一版只做一件事 —— 让它不用再问人。

**设置面板里的扩展说明，从一段话改成四步清单：**

1. 下载并解压（明确写了：解压目录不要删、不要挪）
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启「开发者模式」
3. 点「加载已解压的扩展程序」，选**含 `manifest.json`** 的那个文件夹
4. 粘贴访问令牌，端口保持默认

旁边新增了「下载扩展包」按钮，一点直接打开官网的 zip 下载，不用再满官网找。

还补了一段排障顺序，按这个顺序查，基本都能自己解决：

- 钥匙窝是不是没解锁（锁定时拿不到凭证）
- 扩展里填的端口，和设置页显示的是否一致
- 是不是点过「重新生成令牌」（重新生成后必须重新粘贴）
- 换过浏览器用户、或重装过浏览器，第 2、3 步要重做

**官网同步改了：**

- 「浏览器扩展」小节改成同样的四步，末尾加了排障说明
- 顶部导航加了「GitHub」，页脚加了「源码在 GitHub」
- 更新日志里把 v1.3.0 的两条标了 `NEW`
- 下载区的版本号、校验命令行统一到 1.3.0

**顺带纠正一处旧文案。** 以前 README 里写「首次启用会显示令牌，扩展会自动读取」—— 这是错的，扩展必须手工粘贴令牌，现在改对了。

## 五、官网这条线：域名、证书、备案、开源

软件之外的作业，比想象中多。

**域名统一到 www。** 早期 sitemap、canonical 里写的都是根域名，但根域名的解析一度没指到我们的服务器 —— 搜索引擎抓到的是死链。现在两个域名都指向同一台机器，并且统一 301 到 `https://www.yaoshiwo.cn`：同一份内容不留两个地址，对收录更干净。

**HTTPS。** 用 Let's Encrypt 签发，证书同时覆盖 `yaoshiwo.cn` 和 `www.yaoshiwo.cn`，HTTP 一律 301 到 HTTPS。部署脚本里还专门留了一条：`/.well-known/acme-challenge/` 在 80 端口不做跳转 —— 否则证书续期时校验请求会被跳走，续期就失败了。这种坑不会当场报错，通常是三个月后才发现。

**备案。** ICP 备案已通过，编号 **陕ICP备2026029660号**，按监管要求放在首页底部中间位置，并链接到 <https://beian.miit.gov.cn/>。页脚同时预留了公安联网备案的位置，拿到号直接填。

**开源。** 源码以 MIT 许可公开在 <https://github.com/liwg1/yaoshiwo>，安装包同时发 GitHub Releases。构建流水线也公开：打一个 tag，就自动出 Windows 安装包、算好 SHA256、发 Release。

**校验值三处一致。** 官网下载区、GitHub Release 附件、`SHA256SUMS.txt` 给的是同一个哈希。你从哪儿下都能核对：

```
certutil -hashfile YaoShiWo-Setup-1.3.0.exe SHA256
```

## 六、还剩什么没做（也说一声）

- **搜索引擎收录**需要时间。新站刚上线、外链还少，搜品牌词不一定立刻能搜到。站长验证和 sitemap 提交我们列了清单，等你从百度和必应后台拿到验证码就填。
- **访问统计**还没接。接第三方统计要放宽页面的 CSP，这件事宁可不做也不乱做 —— 一个讲「数据只在你电脑上」的软件，官网上挂满跟踪脚本实在不好看。
- **公安联网备案**是备案后 30 日内的事，属于走流程的活。
- **macOS / Linux 版**暂时没有。现在的构建链路只出 Windows 包。

我们宁愿把这些写出来，也不想让「看起来都做完了」变成一种误导。

---

## 七、怎么升级

1. 打开 <https://www.yaoshiwo.cn> 下载 `YaoShiWo-Setup-1.3.0.exe`，直接覆盖安装（设置和数据库不受影响）
2. 浏览器扩展重新加载一次：`chrome://extensions` → 找到钥匙窝 → 点刷新；或按四步重新加载解压后的目录
3. 官网下载后建议顺手核一下 SHA256
