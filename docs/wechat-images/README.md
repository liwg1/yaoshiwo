# 公众号配图（v1.2.0 → v1.3.0 更新记录）

五张图，全部由 `scripts/render-wechat-images.cjs` 用 Electron 渲染 HTML 生成（@2x，公众号后台直接上传）。
源文件在 `src/`，改文案只改 HTML，然后重跑：

```bash
node node_modules/electron/cli.js scripts/render-wechat-images.cjs
```

## 说明

- 配色沿用官网：深蓝底 `#0b1220`，青色 `#38bdf8` / `#7dd3fc`，靛蓝 `#6366f1` / `#a5b4fc`，绿色表示「已完成」。
- 字体用系统中文字体「微软雅黑」，跨机器渲染时排版可能略有差异；公众号以图片为准，不受影响。
- 尺寸按 @2x 输出：公众号正文建议宽度 ≤ 900px，2 倍图在手机上更清晰；封面用 2.35:1 那张。
- 正文里如果还要截图（真实界面），建议优先用「设置面板四步清单」和「扩展下拉列表」两处实拍，比示意图更有说服力。
