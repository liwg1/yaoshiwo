# 钥匙窝 自动填充（Chrome 扩展）

配合 钥匙窝 桌面端使用：浏览到已保存的网站时，自动填充账号密码，无需手动复制粘贴。

## 安装步骤

1. **启动并解锁 钥匙窝**
2. 点击右上角 ⚙️ **设置** → 找到 **「浏览器扩展（自动填充）」**
   - 确认状态为 **已启用**
   - 点击令牌旁的 **复制** 按钮（📋）
3. 打开 Chrome，地址栏输入 `chrome://extensions`
4. 打开右上角的 **「开发者模式」** 开关
5. 点击 **「加载已解压的扩展程序」**，选择本文件夹（`chrome-extension`）
6. 点击浏览器工具栏中的 钥匙窝 图标，把刚才复制的 **访问令牌** 粘贴进去，点 **保存并连接**
   - 状态显示 **已连接** 即配对成功

## 使用方式

- **输入框内联图标（推荐）**：打开已保存网站的登录页时，账号/密码输入框右侧会自动出现一个**蓝色钥匙图标**，点一下即可在弹出列表中选择条目直接填充——**不用再打开扩展弹窗**
- **自动填充**：登录页加载时会自动填入匹配的账号密码（可在弹窗中关闭此功能）
- **手动填充（弹窗）**：点击浏览器工具栏的 钥匙窝 图标，在列表中点击「填充」
- 仅当条目的「网址」字段域名与当前网页域名匹配时，才会出现图标 / 执行填充

> 如果某个页面没有出现内联图标，通常说明：钥匙窝 里没有与该域名匹配的条目；或登录框位于特殊组件中（如 iframe 嵌套、Canvas 绘制），此时可用弹窗的「填充」按钮。

## 保存新密码（注册新网站）

在网站上注册或首次登录、提交表单后，页面右上角会弹出提示：

> 🔑 **保存登录信息到 钥匙窝？**
> username · example.com
> `[保存]` `[忽略]`

点「保存」即自动写入 钥匙窝：

- 该**域名 + 用户名**已存在 → **更新密码**（并保留历史版本）
- 否则 → **新建条目**（标题使用域名）

说明：

- 若该账号密码**已存在**于 钥匙窝（例如刚自动填充过），则**不会重复提示**
- **页面跳转后提示依然会出现**，登录后跳转的场景也能正确保存
- 可在扩展弹窗底部关闭「注册/登录时提示保存新密码」
- 保存需要 钥匙窝 **处于解锁状态**；若已锁定，提示条会提示你先解锁
- 仅当条目的「网址」字段域名与当前网页域名匹配时，才会出现图标 / 执行填充

## 安全说明

- 本地服务只监听 `127.0.0.1`，不对局域网/外网开放
- 所有请求都必须携带访问令牌，令牌可在 钥匙窝 设置中随时重新生成
- **钥匙窝 锁定（或退出）后，本地服务立即清空凭证**，扩展无法获取任何密码
- 凭证仅在内存中保存，不会写入扩展存储；扩展存储里只保存令牌与端口

## 常见问题

| 现象 | 解决办法 |
| --- | --- |
| 显示「未连接」 | 确认 钥匙窝 已启动；确认设置里扩展服务为「已启用」 |
| 显示「令牌无效」 | 在 钥匙窝 设置中重新复制令牌，粘贴到扩展弹窗保存 |
| 显示「已锁定」 | 在 钥匙窝 中解锁密码库 |
| 没有匹配条目 | 检查该条目的「网址」字段是否包含当前网站域名 |
| 不自动填充 | 部分网站登录框在 iframe 或特殊组件中，可用弹窗中的「填充」按钮手动填充 |
